# Gerenciador-de-tarefas

Projeto com o bjetivo de organizar tarefas do cotidiano, utilizando HTML, CSS e Javascript. O sitema permite adicionar uma tarefa nova, marca-la como concluida e desfazer a conclusão tanto como podendo excluir a tarefa.
Também mostra a quantidade de tarefas pendentes e salva as informações caso a página do navegador seja atualizada.
